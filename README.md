#  LangChain Deep Dive

A hands-on project demonstrating how to build modular LLM applications using LangChain.

---

##  Overview

This project explores core LangChain components and shows how to design structured AI pipelines instead of simple LLM calls.

---

##  Tech Stack

- Python  
- LangChain  
- OpenAI API  
- FAISS  

---

##  Features

- LLM Integration  
- Prompt Templates  
- Chains  
- Memory  
- Agents & Tools  
- Vector Store (FAISS)  
- RAG Pipeline  

---

##  Architecture

User Input → Prompt → LLM → Chain → Agent → Tool → Output
